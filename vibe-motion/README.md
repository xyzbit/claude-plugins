# Vibe-Motion Plugin

Create product-level promotional videos and animations using vibe-motion (Remotion).

## Skills

### `vibe-motion:promo`

Create landing page media, mockups, or promotional videos that require 1:1 realistic UI recreation and smooth interactions.

**When to use:** When the user wants to build promotional videos with realistic UI animations.

## Usage

This plugin is automatically activated when working on promotional video projects using Remotion/vibe-motion.

## Requirements

- Node.js environment for Remotion project setup
- Access to the target frontend codebase for UI recreation
